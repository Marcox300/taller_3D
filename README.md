# Parte 1: 🖥️ Interfaz y manejo de Blender

Blender es un programa de modelado y creación 3D que permite diseñar objetos, crear escenas, esculpir modelos, generar animaciones y renderizar imágenes.

## Interfaz principal

La interfaz se divide en diferentes áreas de trabajo (*Workspaces*), cada una diseñada para una tarea específica: **Modelado, Esculpido, Edición UV, Animación, Renderizado**, entre otras. Se pueden personalizar según las necesidades del proyecto.

- **Modo Objeto (Object Mode):** permite seleccionar, mover, rotar, escalar y organizar objetos completos.
- **Modo Edición (Edit Mode):** permite modificar la geometría de un objeto mediante vértices, aristas y caras.
- **Escenas (Scenes):** contienen objetos, cámaras, luces y otros elementos que forman una composición.
- **Colecciones (Collections):** organizan los objetos en grupos para mantener el proyecto ordenado.

## Modelado y visualización

Blender ofrece distintos modos de visualización: estructura alámbrica (*Wireframe*), sólido (*Solid*), previsualización de materiales (*Material Preview*) y renderizado (*Rendered*). También permite cambiar la vista entre perspectiva y ortográfica, y ajustar el zoom, la posición y la orientación de la cámara de trabajo.

Los atajos de teclado agilizan el trabajo. Los más importantes son `G` para mover, `R` para rotar, `S` para escalar y `Tab` para alternar entre Modo Objeto y Modo Edición. El tamaño y la escala pueden ajustarse libremente o restringirse a los ejes `X`, `Y` y `Z`.

## Otras funciones

- **Esculpir:** modelar formas orgánicas utilizando pinceles digitales.
- **Fotografía y renderizado:** crear imágenes finales con cámaras, iluminación y materiales.
- **Animación:** dar movimiento a objetos mediante fotogramas clave (*keyframes*) y una línea de tiempo.
- **Materiales y texturas:** definir colores, superficies y apariencia visual.

En resumen, Blender combina modelado, organización de escenas, edición de geometría, visualización y animación dentro de una interfaz personalizable que permite adaptar el entorno a cada tarea.
